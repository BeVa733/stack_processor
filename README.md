# Soft Processor Unit Infrastructure

Проект представляет собой реализацию полноценной вычислительной системы: **Assembler**, **Soft Processor Unit (SPU)** и контейнер **Stack** с защитой данных. 

Система позволяет компилировать текстовые файлы с инструкциями в байт-код и выполнять их на виртуальном процессоре. 

## Модули системы

Проект разбит на независимые логические блоки:
### 1. **Stack Library (/stack)**

**Назначение:** Ядро системы, обеспечивающее хранение данных.

**Технические детали:** 
* Реализована защита от повреждения данных (`Canary protection` и `Hashing`) для обеспечения стабильности SPU.
* Реализована система вывода полной информации о состоянии контейнера при обнаружении ошибки (`Dump system`)

### 2. Assembler (/asm)

**Назначение:** Трансляция ассемблерного кода (.asm) в бинарный файл, исполняемый процессором.

**Технические детали:** 
* кеализована система двухпроходного ассемблирования (`Two-pass assembler`)
* Поддержка словесных меток, автоматический расчет адресов переходов 
* Генерация заголовка с `сигнатурой` и `версией`.
* Генерация листинга ассемблируемого кода.

### 3. SPU — Soft Processor Unit (/spu)

**Назначение**: Эмулятор процессора, исполняющий байт-код.

**Технические детали:**
* Стек-ориентированная машина
* Поддержка арифметических операций, регистров общего назначения (`AX`, `BX`, `CX`, `DX`) и оперативной памяти (`RAM`)
* Проверка исполняемого файла на корректность  

### 4. Disassembler (/asm/disasm)

**Назначение**: Обратное преобразование байт-кода в текстовый формат для отладки и анализа.

## Система команд (ISA)

Процессор поддерживает набор инструкций для вычислений и управления логикой:

* Работа со стеком: `PUSH`, `POP`, `PUSHREG`, `POPREG`.

* Арифметика: `ADD`, `SUB`, `MUL`, `DIV`, `POW`, `SQRT`.

* Управление: `JMP` (Безусловный), `JA`, `JB`, `JE` (Условный), `CALL`, `BACK` (обработка процедур), `HLT` (Останов).

* Ввод/вывод: `IN`, `OUT`, `OUTC` (символ).

* Память и Графика: `POPM` (Запись в RAM), `DRAW` (Вывод содержимого видеопамяти в консоль).

* Для ОС Windows возможен вывод видопамяти в окно: `WDRAW`

## Архитектура бинарного файла

Байт-код имеет строгую структуру для предотвращения запуска несовместимых программ:

* Signature: "BEBA".

* Version: Текущая версия системы команд.

* Bytecode: Последовательность команд и их аргументов.

## Структура репозитория
```Plaintext
.
├── asm/            # Исходники ассемблера и дизассемблера
├── spu/            # Исходники виртуального процессора
├── stack/          # Защищенная библиотека стека
├── include/        # Общие заголовочные файлы и определения команд
├── tests/          # Примеры программ
└── Makefile        # Универсальный скрипт сборки
```

## Быстрый запуск

Сборка всех модулей осуществляется одним вызовом из корневой директории:
```bash
make                #для полной сборки проекта
make clean          #для удаления собранных файлов 
```
Требуемое окружение: g++.

### Пример использования:

Написание кода: Создайте файл program.asm.

Компиляция:
```bash
# Имя выходного файла опционально (по умолчанию asm_output.bin)
./asm.out program.asm program.bin
```
Запуск:
```bash
# Имя исполняемого файла опционально (по умолчанию asm_output.bin)
./spu program.bin
```
